Template-wide

Information.json (Arches resource model)

  • Most structural changes came from Renier's v2 demo export (2026-09-08, commit 1541133), which he marked as "not yet finished" for Info. It changed several CIDOC properties: Author L33 has maker → P70 documents; Publisher L33 has maker → P105 right held by; URL → P130 shows features of; Book or journal edition → P148 has component; Book or journal information → P129 is about; Volume → P3 has note; Publication information → P70i is documented in; Page numbers class E60 Number → E62 String.
  • Cards restructured: Resource Type card merged into Publication information; Recorder and Resource version control merged into Recording details; new Uploading details card (E66 Formation).
  • Nodes renamed: Zotero key → Zotero Key, Resource Type → Resource type, Languages → Language, Resource created at → Created at, Resource last modified at → Last modified at.
  • Nodes added: Comment, Abstract Note, APA Reference, Uploader, Uploaded at.
  • Node descriptions filled for every field, synced with the template's Definition (En); Resource type and Publisher rewritten on 2026-09-25.
  • exportable switched on for MAEASaM ID, ISSN and Copyright (Task #90).
