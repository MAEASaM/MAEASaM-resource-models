Things changed

structure, names, vocabularies, definitions

Template-wide

  • Every English definition rewritten to the shared style (2026-09-25): 23 copied from the matching Site fields approved the same day (measurements, condition, disturbance and threat fields), 25 RS-specific ones approved one by one; earlier September work had already standardised the Recording/Uploading/Copyright ones. Question-form definitions ("What is the land use…", "How certain are you…"), "This node records / It records", EDTF instructions and typos are gone. Decision
  • Collection notation changed from "Vocabulary: X" / "Resource model: X" to X (cv) / X (rm), and vocabulary names aligned with the Thesaurus (e.g. Dimension type/unit → Measurement types (cv) / Measurement units (cv), Official division → Geometry qualifiers (cv)).
  • Activity, survey, assessment and image dates moved from Date to EDTF.
  • Leftover notes in row 22 ("Site Resource Model", "Actor Model"…) removed.
