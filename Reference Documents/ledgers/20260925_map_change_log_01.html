Things changed

structure, names, field values, Map.json

Template-wide

  • All field and group names put in sentence case on 2026-09-25 (e.g. Map Name → Map name, Digital File Name → Digital file name, Map Details → Map details), in the template and in Map.json. The shared Copyright/Access, Rights Notes and Preferred Citation names are left for an all-model rename (Task #107). Decision
  • Collection names lower-cased to the vocabulary names (Map Types (cv) → Map types (cv), Document Conditions, Digitisation Methods, Access Levels), and Grids (rm) → Grid (rm).
  • Dublin Core values rewritten from the short dcterms: form to full http://purl.org/dc/terms/… URIs and completed for every field.
  • Input-instruction sentences ("Please write the term exactly…", "Please enter the date using EDTF…", "Please enter Yes or No") removed from 12 English and 9 French definitions — they now live only in the Input Instructions row.
  • Publication, digitisation, georeference and clipping dates moved from Date to EDTF.
  • Eleven reviewer notes that sat in row 24 of the template were moved to Task #106.

Map.json (Arches resource model)

  • Map.json was built by the project team, not exported from the CIDOC reviewers' work: first generated on 2026-09-06 by Scripts/generate_map_resource_model.py with placeholder CIDOC classes, then fixed through four real Arches import attempts (Tasks #86, #87, #89) and is now import-tested. CIDOC by us
  • Since generation: 42 node names changed, 13 CIDOC properties and 10 classes changed, 54 descriptions written or synced with the template's Definition (En).
  • 2026-09-25: Datum, Ellipsoid (was Spheroid) and Unit of measure (was Unit of) changed from free text to concept lists, linked to the live Arches collections Datum, Ellipsoid and Measurement unit; class E55 Type via P2 has type; select widget instead of a text box. CIDOC by us
  • 2026-09-25: node, card and widget names put in sentence case (96 names; aliases unchanged); 21 descriptions updated. A re-import is needed.
