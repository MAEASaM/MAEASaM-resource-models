Things changed

structure, names, vocabularies, definitions

Template-wide

  • Converted to the shared 22-row layout: DS's draft had no Semantic Node Class row (its "Semantic" row actually held the Node Class and the next row the scope note), two extra "Card"/"*" marker rows and no Input Instructions row.
  • Tail replaced by the standard blocks (by Orhun, 2026-09-24): Resource version control, the old Copyright/access fields and Attribution were replaced by Sources + the shared Copyright/Access block (Licence, Access level, Rights holder, Rights Notes, Preferred Citation) + Recording details (Recorder, Comment, Created at) + Uploading details (Uploader, Uploaded at, Last modified at), identical to Map.
  • Every English definition rewritten to the shared style: "Records the …" → "The …" (66 definitions), and 49 more rewritten one by one — a French text in Basis of condition assessment, question-form definitions ("Who was…", "What recommendation can you make…"), "This node records / It records", typos and fragments. Decision
  • Vocabulary notation and names aligned with the Thesaurus (e.g. Vocabulary: Heritage types → Site types (cv), Dimension type/unit → Measurement types (cv) / Measurement units (cv), EPGS → EPSG (cv)); Data Type values aligned with the rules (Concept list → Concept-list, Bolean → Boolean, Geometry → GeoJSON-feature-collection); CIDOC class casing fixed.
  • Excel-damaged example dates restored to ISO format; stray third examples in row 22 removed; reviewer note on Created at moved to the Task List.
